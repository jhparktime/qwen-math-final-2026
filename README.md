# Qwen2.5-3B Integer Math — R3 Final Reproduction

Reproducible inference repository for **아주 소중한 딥러닝 챌린지 2026**.
The permitted base is fixed to `Qwen/Qwen2.5-3B-Instruct`. The deployment
candidate is the frozen **R3 R2-continuation LoRA**; it runs locally and makes
no external API, search, or answer-lookup call.

## Deployment method

```text
Qwen2.5-3B-Instruct + frozen R3 LoRA
    -> SC16, 2,048 output tokens
    -> only capped sample indices: 4,096, then 8,192 when still capped
    -> conservative stronger-consensus length router
    -> PAL4 only when original SC16 margin <= 1
    -> use PAL only with >=3/4 identical executable results
    -> normalized integer plurality / earliest-sample tie break
```

The PAL programs are generated by the same Qwen base and R3 adapter. They run
locally in isolated Python with an AST allowlist and resource limits. No test
question leaves the runtime.

## A100 Colab setup

Use a fresh A100 40 GB runtime. Before the official inference window, clone
the repository and cache the pinned base model and adapter:

```bash
git clone https://github.com/jhparktime/qwen-math-final-2026.git
cd qwen-math-final-2026
pip install --no-cache-dir -r requirements-colab.txt
python scripts/prefetch_model.py
python scripts/fetch_frozen_adapter.py
```

If vLLM or Transformers was imported before installation, restart the runtime
once. Adapter download and model caching are setup-only. The official
inference command sets Hugging Face and Transformers offline modes before it
loads either model or adapter.

## Required local file

Organizer datasets are not committed. Put the final question file here:

```text
inputs/deep_chal_math_test.csv
```

It must have unique `id` values and non-empty `question` values. An input with
a non-empty `answer` column is rejected.

## Final inference

```bash
PYTHONPATH=. python inference/final_inference.py \
  --input inputs/deep_chal_math_test.csv \
  --adapter artifacts/r3_r2continue_adapter \
  --output-dir runs/final-private
```

The command is resume-safe. Re-run the exact same command after an
interruption; completed problem IDs are read from append-only JSONL artifacts.

Validate the resulting CSV:

```bash
python scripts/validate_submission.py \
  --input inputs/deep_chal_math_test.csv \
  --submission runs/final-private/submissions/submission.csv \
  --expected-rows 2000
```

The result has exactly `id,answer` in original input order. Every answer is a
signed integer string and is never converted through floating point.

## Reproducibility checks

```bash
PYTHONPATH=. pytest -q
```

Before submission, retain the Git commit hash and
`final_inference_report.json`, and verify:

- adapter SHA-256 matches the value above;
- final input contains 2,000 unique IDs;
- the output has 2,000 `id,answer` rows in the original order;
- every answer matches `^-?\d+$`;
- no organizer data, API key, cached base model, raw prediction, or submission
  file is committed.
