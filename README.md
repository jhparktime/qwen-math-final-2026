# Qwen2.5-3B Integer Math — Final Reproduction

Reproducible final-inference repository for **아주 소중한 딥러닝 챌린지
2026**. The permitted base is fixed to `Qwen/Qwen2.5-3B-Instruct`; inference
runs locally with one frozen LoRA adapter and never calls an external API.

## Final method

```text
Qwen2.5-3B-Instruct + frozen R2 Pro4-hint LoRA
    -> SC16, 2,048 output tokens
    -> capped sample indices: 4,096, then 8,192 when still capped
    -> conservative stronger-consensus length router
    -> PAL4 only when original SC16 margin <= 1
    -> use PAL only with >=3/4 identical executable results
    -> exact integer plurality / earliest-sample tie break
```

The PAL programs are generated by the same Qwen base and LoRA. They execute
locally in isolated Python with an AST allowlist and resource limits. No test
question leaves the runtime.

## A100 Colab setup

Use a fresh A100 40 GB runtime. Clone the public repository and install the
tested inference stack:

```bash
git clone https://github.com/jhparktime/qwen-math-final-2026.git
cd qwen-math-final-2026
pip install --no-cache-dir -r requirements-colab.txt
```

If vLLM or Transformers was imported before installation, restart the runtime
once. Cache the pinned base model before the official inference window:

```bash
python scripts/prefetch_model.py
```

The inference program enables Hugging Face and Transformers offline modes
before loading the model.

## Required local files

Organizer datasets are not committed. Put the final question file here:

```text
inputs/deep_chal_math_test.csv
```

Fetch the frozen adapter once while network access is available:

```bash
python scripts/fetch_frozen_adapter.py
```

The input must contain unique `id` values and non-empty `question` values. A
non-empty `answer` column is rejected. The adapter weight is hashed before the
model is loaded. Adapter download is setup-only; the inference command enables
offline Hugging Face and Transformers modes before loading the model.

## Final inference

```bash
PYTHONPATH=. python inference/final_inference.py \
  --input inputs/deep_chal_math_test.csv \
  --adapter artifacts/r2_pro4_hint_adapter \
  --output-dir runs/final-private
```

The command is resume-safe. Re-run the exact same command after an interruption;
completed problem IDs are loaded from append-only JSONL files.

Validate the resulting submission:

```bash
python scripts/validate_submission.py \
  --input inputs/deep_chal_math_test.csv \
  --submission runs/final-private/submissions/submission.csv \
  --expected-rows 2000
```

The submission contains exactly `id,answer` in original input order. Answers
are signed integer strings and are never converted through floating point.

## Reproducibility checks

Run the dependency-light unit tests on any Python environment:

```bash
PYTHONPATH=. pytest -q
```

Before submission, verify:

- the adapter SHA matches the value above;
- the final test contains exactly 2,000 unique IDs;
- `submission.csv` has exactly 2,000 rows and `id,answer` columns;
- every answer matches `^-?\d+$`;
- the Git commit hash and `final_inference_report.json` are retained;
- no organizer data, API key, model cache, raw prediction, or submission file is
  committed to Git.
